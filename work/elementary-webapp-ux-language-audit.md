# Elementary Learner Language Audit

감사일: 2026-08-31
대상: `src/components/screens/ClueInvestigationScreen.tsx`, `src/components/screens/ComparisonScreen.tsx`와 연결된 학생 노출 문구
기준: 2022 개정 국어과 초등 3~4학년군 적응 문구, `child-language-rubric.md`, `student-personas.md`

## 범위와 방법

후보 수집 스크립트 결과(`work/elementary-webapp-ux-language-candidates.md`)에는 테스트 코드와 기존 작업 문서의 문자열도 포함되어 있어, 이 감사에서는 실제 runtime JSX와 화면에 노출되는 콘텐츠만 다시 확인했다. 교육과정·사전·포용성 승인 문서의 24개 장면과 8개 문장 정비 문구는 의미를 바꾸지 않는 범위에서 유지한다.

주 사용자 준호(초등 3~4학년)는 짧은 문장을 읽고 바로 다음 행동을 찾을 수 있어야 한다. 감사 항목은 한 문장 길이, 익숙한 낱말, 해야 할 행동의 명확성, 실패를 부끄럽게 만들지 않는 표현, 색에 의존하지 않는 안내다.

## 읽기·표현 판정

- `단서`, `뜻`, `고르다`, `살펴보다`는 화면 전체에서 반복되어 맥락으로 익히기 쉽다.
- `어절`은 교육과정 용어로 정확하지만 첫 지시문에서는 `말`이 더 빠르게 이해된다. 내부 검수 문서의 `어절` 표현은 유지하고 학생 노출 문장만 바꾼다.
- `판단하기 어려움`은 모르는 답을 허용하는 핵심 학습 계약이므로 더 쉬운 말로 바꾸지 않는다. `잘 모르겠어요`와 혼동하지 않고, 뜻 선택지의 이름으로 유지한다.
- 경쟁·속도·점수 표현, 성별 고정관념, 신체·가정환경 평가, 사전 권위 과장은 새 문구에 넣지 않는다.
- 음성·재생·녹음·VoiceOver를 암시하는 문장을 추가하지 않는다. 기존 `소리 없이도 읽어도 괜찮아요`는 text-only 범위 안내로 유지한다.

## 등급

- P0: 없음. 학습을 막거나 개인정보·안전에 영향을 주는 문구 결함은 발견하지 않았다.
- P1: 없음. 기존 리디자인의 첫 CTA·진행 표시 계약이 375px 기준 테스트를 통과한다.
- P2: 위 두 문구. 학습 행동은 가능하지만 첫 안내를 해석하는 시간이 늘어날 수 있다.
- P3: 제목의 음절 단위 줄바꿈과 token affordance는 언어 자체가 아닌 읽기·UI 발견성 이슈로 별도 구현 항목에서 다룬다.

1. 새 문구가 실제 화면의 `#clue-help`, `#necessity-help`에 나타난다.
2. 문구가 설명만 하고 끝나지 않고, 어린이가 눌러야 할 말·살펴볼 판단을 직접 가리킨다.
3. 기존 evaluator/reducer의 decision 값과 학습 기록은 변하지 않는다.
4. `npm run test:run`, lint, build, responsive·screen-reader·student-flow E2E에서 문구와 접근성 description이 통과한다.
5. 실제 초등학생·교사 승인과 VoiceOver는 이 감사의 증거가 아니며 별도 범위로 남긴다.
